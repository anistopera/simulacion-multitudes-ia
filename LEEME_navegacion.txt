USO DESDE EL PROGRAMA PRINCIPAL
-------------------------------
from modulos.entorno import Entorno
from modulos.navegacion_astar import NavegadorAdaptativo

entorno = Entorno(configuracion="configuracion.json")
nav = NavegadorAdaptativo(entorno, modo="B")     # "A" = ruta fija

# Al crear los agentes (cada uno: dict u objeto con id, x, y, destino, ruta):
for ag in agentes:
    nav.asignar_ruta_inicial(ag, t=0.0)

# Una vez por segundo, despues del diagnostico (D: matriz 10 x 15, valores 0-1):
nav.actualizar_todos(agentes, t, D)

Contrato con los demas modulos
- agente['ruta'] queda como lista de waypoints (x, y) en metros (centros de celda).
  El reparto no fija este formato; si Jhosselin usa otro, cambiar celdas_a_waypoints().
- D es la matriz del diagnostico por celdas de 2x2 m, forma (alto/2, ancho/2) = (10, 15),
  con D = min(1; densidad/2,0). Si Santiago entrega otra forma, avisar.
- Si el agente no tiene 'destino', se usa entorno.destino (la salida).
