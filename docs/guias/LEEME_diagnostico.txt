USO DESDE EL PROGRAMA PRINCIPAL
-------------------------------
from modulos.entorno import Entorno
from modulos.diagnostico import DiagnosticoCongestion

entorno = Entorno(configuracion="configuracion.json")
diag = DiagnosticoCongestion(entorno=entorno)

# Tras diez pasos físicos de 0.1 s:
estados, D = diag.actualizar(motor.agentes_activos, dt=1.0)

# D es la matriz (10, 15) que consume el navegador A* de Keyla:
nav.actualizar_todos(agentes, t, D)

CONTRATO CON LOS DEMÁS MÓDULOS
------------------------------
- Entrada: lista de agentes (dicts, objetos con x, y, vx, vy, v_deseada o tuplas de telemetría).
- Salida para Keyla (A*): Matriz D de forma (10, 15), con valores entre 0.0 y 1.0 (D = min(1, dens/2.0)).
- Salida para Wendy (Visualización): diag.densidad (personas/m²), no D ni estados.
- Estados disponibles para análisis: cadenas ('libre', 'acumulacion', 'critica')
  o diag.estados_codigo (-1: obstáculo, 0: libre, 1: acumulación, 2: crítica).

RESULTADO DE LA DEMOSTRACIÓN CINEMÁTICA CON 120 AGENTES
--------------------------------------------
- Densidad pico: 29.25 ag/m² frente al paso principal de 2 m.
- Velocidad media: se reduce a < 0.15 m/s.
- Primera celda crítica a los 6.0 segundos (superando los 3 s de persistencia requeridos).
- La demostración usa frenado prefijado y admite solapamientos; no valida el motor físico.
- En los 18 episodios integrados el pico observado fue 4.0 ag/m².
